# Planning Workspace

This directory holds the collaborative artifacts we create while shaping the engineering plan for the demo project. As we clarify goals, make assumptions, or lock in decisions, we will capture them here so the entire team can follow along.

## Structure
- `log.md` — running notes from our conversations, including open questions and decisions.
- `engineering-plan.md` — the evolving lightweight engineering plan for the demo build.

Feel free to add more files if new categories of information become helpful.
